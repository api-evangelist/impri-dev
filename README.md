Impri provides a human‑in‑the‑loop approval inbox for AI agents, letting developers gate actions such as refunds, emails, deployments, or database changes behind a human decision. The service offers a hosted cloud version with a free tier and an open‑source self‑hosted option, detailed documentation, SDKs, and webhook integrations to ensure safe, auditable AI operations.

**Areas:** AI · Human-in-the-loop · Approval · Automation · SaaS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Impri: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
